# Calligraphy Ideas 🖋️

A minimalist web application designed to provide instant inspiration for calligraphy practice. Users can filter by mood and sentence length to find the perfect quote for their next piece of art.

**Check out the live site here:** [Calligraphy Prompts](https://calligraphy-ideas.vercel.app/)

## ✨ Features

* **Mood-Based Filters:** Choose from categories like *Happy & Joyful*, *Spiritual & Divine*, *Motivational*, and *Poetry*.
* **Customizable Length:** Use the slider to select exactly how many words you want to write (1-10 words).
* **"Surprise Me" Mode:** Get a completely random quote for a spontaneous practice session.
* **Responsive Design:** A dark-themed, elegant UI that looks great on both desktop and mobile devices.

## 🛠️ Built With

* **HTML5/CSS3:** For the structure and elegant dark-mode styling.
* **JavaScript (ES6):** Logic for filtering quotes and handling user interactions.
* **Vercel:** Used for seamless deployment and hosting.

## 📂 Project Structure

```text

├── script.js        # Core logic for quote generation
└── data.js          # The library of calligraphy quotes
```
